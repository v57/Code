# Keyboard Shortcuts

These are the Mac app's shortcuts. The iPhone and iPad app has none of its own.

## File

| Command | Shortcut |
|---|---|
| New File… | ⌘N |
| New Window | ⇧⌘N |
| Open Folder… (⌘O in a window without a project) | ⇧⌘O |
| Save | ⌘S |
| Save All | ⌥⌘S |
| Open in New Window | ⇧⌘D |
| Close Tab (the window, when no tab is open) | ⌘W |
| Close Other Tabs | ⌥⌘W, or ⌥-click a tab's close button |
| Close Window | ⇧⌘W |

## Edit and Editor

| Command | Shortcut |
|---|---|
| Find in the file | ⌘F |
| Find in Project… | ⇧⌘F |
| Toggle Comment | ⌘/ |
| Indent | ⌘] |
| Outdent | ⌘[ |
| Show Completions | ⌃Space |
| Select Next Placeholder | ⌃/ |
| Select Previous Placeholder | ⌃⇧/ |

While the completion list is open: ↑ and ↓ choose, Return or Tab inserts, Esc closes it.

## View

| Command | Shortcut |
|---|---|
| Show or Hide Navigator | ⌘0 |
| Show Project Navigator | ⌘1 |
| Show Find Navigator | ⌘3 |
| Show Issues | ⌘5 |
| Show or Hide Hidden Files (in Open Quickly: include them) | ⇧⌘. |
| Wrap Lines | ⌥Z |
| Minimap | ⌃⇧⌘M |
| Show or Hide Console | ⇧⌘Y |
| Zoom In | ⌘+ |
| Zoom Out | ⌘- |
| Actual Size | ⌃⌘0 |

## Go

| Command | Shortcut |
|---|---|
| Open Quickly… | ⌘O |
| Open the first result of Open Quickly's second group | ⌘↩ |
| Go to Line… | ⌘L |
| Next Tab | ⇧⌘] |
| Previous Tab | ⇧⌘[ |
| Reveal in Sidebar | ⇧⌘J |
| Jump to Definition | ⌃⌘J, or ⌘-click |
| Show Quick Help | ⌃⇧⌘/, or ⌥-click |
| Go Back | ⌃⌘← |
| Go Forward | ⌃⌘→ |
